# Student Task Tracker 
## Overview 
Students need a simple way to track coursework tasks and see what remains. 
The proposed system will help a student record tasks and mark them complete. 
[it is task tracker that actually helps students to go through their tasks and get helped that how much work they have completed ] 
## Scope - In scope: Add a coursework task with a title. - In scope: List saved tasks. - In scope: Mark a task complete. - Out of scope: Fee payments. - Out of scope: Automatic grading. 
## Stakeholders - Student: Records tasks and checks progress. - Instructor: [that students completed their submission] - Project maintainer: [manage the product performance and working ] 
## Functional requirements - FR-01: The system shall let a student create a task with a title. - FR-02: The system shall display the student's saved tasks. - FR-03: The system shall let a student mark a task complete. 
## Nonfunctional requirements - NFR-01: With 100 saved tasks, the task list shall appear within 
2 seconds in at least 95 of 100 trials on an agreed test device. - NFR-02: Every task action shall work using only a keyboard, 
checked against each documented task workflow. 
## Acceptance criteria - FR-01: Given the title "Read Chapter 1", saving a new task 
makes that title appear in the task list. - FR-02: Given two saved tasks, opening the list shows both titles. - FR-03: Marking an incomplete task complete changes its 
displayed status to Complete. 
## Assumptions and open questions - Assumption A-01: [students will successfully go through their work ] - Question Q-01: [how the authentication system will work and will there be 2 step authentication available] - Question Q-02: Which device will be used to test NFR-01?
